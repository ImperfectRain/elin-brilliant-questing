# Roadmap Dependencies

Current canonical roadmap HEAD is `BQ-055`. Important live-integration dependencies:

- `BQ-037/BQ-038` guild networks and authority: the player's own membership works; rank and per-guild contribution are read from `FactionRelation.rank/exp` since `BQ-038` (`SOURCE-OBSERVED`; `FIX-ELIN-007` implemented and rank shape `STUB-VERIFIED`). They have not been read on a running member save, so the rank scale the authority threshold uses is still unverified. Which of the four guilds a *live NPC* belongs to has no identified read, so BQ-037's routing has no members and BQ-038 has no officer who speaks for a guild in a real game until a generator or an adapter grants the membership role (`ELIN-Q-0025`, `UNRESOLVED`).
- `BQ-039/BQ-040` generation from world state: SourceData indexes and active-zone APIs now provide a first affordance map, but no runtime affordance adapter exists (`SOURCE-DATA`, `SOURCE-OBSERVED`, `UNRESOLVED` integration).
- `BQ-041` onward situation archetypes: use existing SourceData ids for religions, skills, zones, things, recipes, factions, jobs, hobbies, and categories; use conservative actor classification until runtime samples refine thresholds (`SOURCE-DATA`, `SOURCE-OBSERVED`, `UNRESOLVED` runtime).
- `BQ-048/BQ-049` Home integration: BQ now resolves `MaxPopulation` and `AddMemeber`; nonzero Home admission still needs disposable-save validation before it can be treated as live-safe (`SOURCE-OBSERVED`, `STUB-VERIFIED`, `FIX-ELIN-002` implemented).
- `BQ-050/BQ-051` economy/demand: item inventory and currency reads work; production quality now uses total quality/`Quality` rather than rarity, transfer verification handles stack-merged identity, and production provenance remains unsupported until hooks outside `ActPerformed` are identified (`SOURCE-OBSERVED`, `STUB-VERIFIED`, `FIX-ELIN-004` through `FIX-ELIN-006` implemented).
- Recent S6 Core systems: `BQ-047` festival competition, `BQ-051` business continuity, `BQ-053` organization action, `BQ-054` inter-organization relations, and `BQ-055` social obligations are Core/headless systems today. The plugin registers `HomeResidentSituation` escalation and calls generic `ThreadLifecycle`, but it does not yet run a festival scheduler, business adapter, organization heartbeat, favor acquisition/call-in dialogue surface, or autonomous S6 driver in live Elin (`UNRESOLVED`).
- `BQ-135` actor activity snapshot can be implemented read-only from timetable/global-goal fields after runtime sampling confirms ordinary actor populations (`SOURCE-OBSERVED`, `UNRESOLVED` runtime).
